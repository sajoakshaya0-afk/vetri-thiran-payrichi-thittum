# Vetri Thiran Payirchi Thittum

A web-based platform for skill development and training management.

## 🚀 Features
- Responsive Frontend using HTML
- Backend powered by Python (main.py)
- Easy to deploy and manage

## 📁 Files
- index.html - Main frontend page
- main.py - Backend logic
- requirements.txt - Python dependencies

## 🛠️ How to Run
1. Clone the repo:
   git clone https://github.com/sajoakshaya0-afk/vetri-thiran-payirchi-thittum.git
2. Install dependencies:
   pip install -r requirements.txt
3. Run:
   python main.py
